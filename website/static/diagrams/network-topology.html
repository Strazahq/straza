What this shows

Every connection in a Straza deployment, drawn with its direction. Agent machines, operators, the IdM and the IdP all dial the main listener (:8420) inside a private network; agent machines open no inbound port at all. The approver listener (:8443, server.approverTLS, auto-minted by default on standalone and opt-in on enterprise) serves only /v1/approver/* plus /readyz and answers 404 to everything else. It is the one surface designed to face the internet, because the phone app is https-only and pins the listener’s certificate from the enroll QR. Approval pushes and Slack notifications leave strazad outbound-only; the only inbound internet path besides the approver surface is Slack’s interactive-button callback, which needs a deliberately published HTTPS path (the demo stack uses a one-route proxy). Postgres, NATS, upstream MCP servers and SIEM receivers are backends: strazad dials them, nothing else should.
