{{- if .Values.ingress.enabled }}

INGRESS: the rendered rule is path: / (Prefix) on {{ .Values.ingress.host }}, so
admin API, console, /mcp, SCIM and the UNAUTHENTICATED /metrics all answer
there. Right for a restricted host; on a host the internet can reach, split
the surface at the edge instead: publish /v1/approver/* (+ /readyz) only,
rate-limited, and keep console/admin/gateway on a restricted one. Never let
/metrics cross a public ingress: it answers anyone unless server.metricsToken
is set in configYaml, it labels its counts by MCP server, sink, route, status,
effect and lane, and it is best scraped in-cluster over the Service.
{{- end }}
